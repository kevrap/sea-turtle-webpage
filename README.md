**Description** 

**Sea Turtle Conservation** is an awareness website built with HTML, CSS, and JavaScript, designed to educate visitors about Florida's sea turtle species and rally support for a local conservation initiative. The site features a responsive navbar with a dark mode toggle, scroll-triggered reveal animations for content sections (with a "Reduce Motion" accessibility option that instantly disables them for users who prefer a static experience), and dedicated sections covering turtle species identification, nesting habits, and current threats to their survival. It also includes an embedded video and species-specific imagery.

There is live petition feature supporting a residential lighting ordinance to protect nesting sea turtles from light pollution. Visitors can sign the petition through a validated form (checking name, hometown, and email format before submission), which dynamically appends their signature to a running list and updates a live signer count. Signing also triggers an animated thank-you modal with a pulsing image effect, personalized with the signer's name and hometown. The site closes with a curated news section linking to recent sea turtle conservation stories.
